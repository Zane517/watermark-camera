# 今日水印相机

一个纯前端的照片水印工具：选图或拍照，自动叠上时间、经纬度、地址、拍摄人、备注，再导出带水印的原图。
**图片全程在浏览器本地处理，不会上传到任何服务器。没有依赖、不用构建，双击就能打开。**

- 版本：v1.0.2（2026-10-22）
- 环境：Chrome / Edge / Firefox 等现代浏览器，电脑手机都行
- 代码里没有第三方品牌字样，也没有密钥，可以直接分享或传代码仓库
- 开源协议：MIT（见 [LICENSE](LICENSE)）

### 方式三：本地服务器（要用摄像头拍照时）

然后浏览器打开 。
> 摄像头只有在  或  下才能调用；直接双击 HTML 的话，请用「选择图片」。

### 基本流程
1. 点左侧上传区选图，或把图片拖进去；要现场拍就点「打开摄像头现场拍摄」。
2. 时间、经纬度、地址可以自动获取，也能手动填；拍摄人、备注自己填。
3. 右边是实时预览，左边调风格、开关、字号。
4. 点「下载带水印原图」导出，**导出的是原图分辨率，不会被压缩到预览尺寸**。

## 三、配置高德 Key（可选）

不配 Key 也能用，只是「自动反查地址」和「地址转经纬度」这两个功能用不了。

1. 打开高德开放平台 → 控制台 → 应用管理 → 创建新应用 → 添加 Key。
2. **服务平台一定要选「Web 服务」**，选成「Web 端(JS API)」会报 。
3. 打开工具，点右上角 **「配置定位 Key」**，把 Key 粘进去保存。

Key 只存在本机浏览器的  里（键名 ），**不会写进任何源码文件**，换电脑或清了缓存就得重新填。清空输入框再保存就是删除。

## 四、功能说明

### 水印字段
| 字段 | 来源 | 说明 |
|------|------|------|
| 时间 | 自动 / 手动 | 导入图片或点「现在」时自动刷新，也能手改 |
| 纬度 / 经度 | 自动 / 手动 | 「自动定位」取浏览器定位，也支持地址转经纬度 |
| 坐标系 | 自动 | WGS84 或 GCJ-02，见下面说明 |
| 地址 | 自动 / 手动 | 定位后反查，或者直接手填 |
| 拍摄人 / ID | 手动 | 填了才会出现在水印上 |
| 备注 | 手动 | 填了才会出现在水印上 |

### 三种风格
- **经典**：左下信息块（纯白字）+ 画面正中半透明「现场拍照」+ 右下角弧形文字。
- **简洁**：左上角一个信息块，带半透明黑底衬。
- **角落**：和简洁一样，但固定在左下角。

### 可调项
中央水印开关、弧形水印开关（文字可自定义）、时间/经纬度/地址显示开关、底衬开关、字号缩放（1.2–5.0）。

### 坐标系要注意
- 浏览器定位返回的是 **WGS84**，「自动定位」后会自动标成 WGS84。
- 「地址转经纬度」走高德地理编码，返回的是 **GCJ-02**，工具会自动切到 GCJ-02。
- 这两种在国内地图上会差几十到上百米，**取证时别混用**：手动改过经纬度的话，记得同步手动切一下坐标系。

## 六、常见问题

**Q：导出的图有点糊？**
导出用的是原图分辨率加 JPEG 95% 质量；预览区为了流畅用的是 92%，最终以导出的为准。想再高一点就改  里的 。

**Q：弧形文字被裁掉一半？**
字号是按图片对角线自动算的，文字太长会自动缩小。还是太长的话，就缩短文字，或者把字号缩放调小。

**Q：超宽全景图（比如 8000×1000）文字超出画面？**
已经加了保护：信息块比画面还高时会自动缩字号，一般不用管。

**Q：摄像头打不开？**
得用  或  打开，而且浏览器要授权摄像头权限。直接双击 HTML 文件不满足条件——最省事的办法是用在线版（方式零）。

**Q：地址反查一直失败？**
检查 Key 是不是选了「Web 服务」类型、有没有欠费或超限，还有能不能正常访问 。

**Q：手机上能用吗？**
能，推荐直接用在线版（方式零），https 环境下摄像头、定位都能用；还可以「添加到主屏幕」当 App 用，支持离线。本地  打开只能「选择图片」，摄像头用不了；局域网  也不属于安全上下文，摄像头一样用不了。

## 七、隐私与免责

- **隐私**：所有图像处理都在浏览器里完成，图片、定位、Key 都不会离开本机；除了调高德接口，没有别的外部请求。
- **免责**：时间和经纬度可以手动填，所以水印内容**没有防篡改的证明力**。这个工具只适合工作留痕、日常记录和整理，别拿它当唯一的法律证据。
